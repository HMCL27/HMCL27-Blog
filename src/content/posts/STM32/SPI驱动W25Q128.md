# SPI 驱动 W25Q128 Flash

```c
#include "led.h"
#include "delay.h"
#include "key.h"
#include "sys.h"
#include "lcd.h"
#include "usart.h"	 
#include "w25qxx.h"
 				 	
//要写入到W25Q64的字符串数组
const u8 TEXT_Buffer[]={"ELITE STM32 SPI TEST"};
#define SIZE sizeof(TEXT_Buffer)
 int main(void)
 {	 
	u8 key;
	u16 i=0;
	u8 datatemp[SIZE];
	u32 FLASH_SIZE; 
    u16 id = 0;
	 
	delay_init();	    	 //延时函数初始化	  
  NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);//设置中断优先级分组为组2：2位抢占优先级，2位响应优先级
	uart_init(115200);	 	//串口初始化为115200
	LED_Init();		  		//初始化与LED连接的硬件接口
	LCD_Init();			   	//初始化LCD 	
	KEY_Init();				//按键初始化		 	 	
	W25QXX_Init();			//W25QXX初始化

 	POINT_COLOR=RED;//设置字体为红色 
	LCD_ShowString(30,50,200,16,16,"ELITE STM32");	
	LCD_ShowString(30,70,200,16,16,"SPI TEST");	
	LCD_ShowString(30,90,200,16,16,"ATOM@ALIENTEK");
	LCD_ShowString(30,110,200,16,16,"2015/1/15");	
	LCD_ShowString(30,130,200,16,16,"KEY1:Write  KEY0:Read");	//显示提示信息		
	while(1)
	{
		id = W25QXX_ReadID();
		if (id == W25Q128 || id == NM25Q128)
			break;
		LCD_ShowString(30,150,200,16,16,"W25Q128 Check Failed!");
		delay_ms(500);
		LCD_ShowString(30,150,200,16,16,"Please Check!        ");
		delay_ms(500);
		LED0=!LED0;//DS0闪烁
	}
	LCD_ShowString(30,150,200,16,16,"W25Q128 Ready!");    
	FLASH_SIZE=16*1024*1024;	//FLASH 大小为16M字节（W25Q128 = 128Mbit）
 	POINT_COLOR=BLUE;//设置字体为蓝色	  
	while(1)
	{
		key=KEY_Scan(0);
		if(key==KEY1_PRES)	//KEY1按下,写入W25QXX
		{
			LCD_Fill(0,170,239,319,WHITE);//清除半屏    
 			LCD_ShowString(30,170,200,16,16,"Start Write W25Q128...."); 
			W25QXX_Write((u8*)TEXT_Buffer,FLASH_SIZE-100,SIZE);			//从倒数第100个地址处开始,写入SIZE长度的数据
			LCD_ShowString(30,170,200,16,16,"W25Q128 Write Finished!");	//提示传送完成
		}
		if(key==KEY0_PRES)	//KEY0按下,读取字符串并显示
		{
 			LCD_ShowString(30,170,200,16,16,"Start Read W25Q128.... ");
			W25QXX_Read(datatemp,FLASH_SIZE-100,SIZE);					//从倒数第100个地址处开始,读出SIZE个字节
			LCD_ShowString(30,170,200,16,16,"The Data Readed Is:  ");	//提示传送完成
			LCD_ShowString(30,190,200,16,16,datatemp);//显示读到的字符串
		}
		i++;
		delay_ms(10);
		if(i==20)
		{
			LED0=!LED0;//提示系统正在运行	
			i=0;
		}		   
	}
}
```
### 1. SPI协议基础回顾
首先，需要了解一下SPI (Serial Peripheral Interface) 是什么：

- **性质:** 它是一种同步、全双工的串行通信协议。
- **线缆:** 通常使用四根信号线：
    - **SCK (Serial Clock):** 时钟线，由主设备（MCU）产生，用于同步数据传输。
    - **MOSI (Master Out Slave In):** 主设备输出到从设备的单向数据线。
    - **MISO (Master In Slave Out):** 从设备输出到主设备的单向数据线。
    - **CS/SS (Chip Select / Slave Select):** 片选信号，用于告诉哪个从设备当前正在被通信（选中）。

### 2. 代码中SPI的实现角色分析

在您的代码中，所有涉及 `W25QXX_` 的函数都依赖于底层SPI驱动。
#### A. W25QXX_Init()：硬件和协议初始化

- **作用:** 这是最关键的一步。当调用 `W25QXX_Init()` 时，库内部会执行以下操作：
    1. **配置SPI外设:** 设置MCU的SPI模块工作模式（例如主设备模式）、波特率、数据位长度等。
    2. **引脚复用:** 将GPIO引脚设置为SPI功能（MOSI, MISO, SCK, CS）。
    3. **芯片识别 (ID Check):** 通常会通过发送一个特定的命令字节，然后读取闪存芯片返回的JEDEC ID，来确认连接是否成功、芯片型号是否正确。

#### B. W25QXX_ReadID()：SPI数据查询

- **作用:** 这个函数使用SPI协议向W25QXX发送一个“读ID”命令。
    1. MCU通过CS信号选中闪存芯片。
    2. MCU通过MOSI线将命令字节发送给闪存。
    3. 闪存接收到命令后，会通过MISO线将自己的身份信息（ID）传回给MCU。
    4. MCU读取这个ID，并与预期的值进行比对 (`if (id ** W25Q128 || id ** NM25Q128)`) 来判断芯片是否正常工作。

#### C. W25QXX_Write() 和 W25QXX_Read()：数据传输

- **作用:** 这是实际的数据读写操作，它是一个复杂的多步骤SPI序列。
    - **写入 (`W25QXX_Write`):** 闪存的写入过程不是简单地发送数据，而是需要一个完整的命令流：
        1. 选中芯片 (CS Low)。
        2. 发送“写入指令”字节（例如 `0x02`）。
        3. 发送目标地址（高位和低位）。
        4. 发送实际要存储的数据。
        5. 等待闪存完成内部编程/擦除操作：必须读状态寄存器 BUSY 位（或调用 `W25QXX_Wait_Busy`）等待，主循环里的 `delay_ms(10)` 只是 LED 闪烁节拍，不参与写等待。
        6. 取消选中芯片 (CS High)。
    - **读取 (`W25QXX_Read`):** 读取过程也涉及命令和地址：
        1. 选中芯片 (CS Low)。
        2. 发送“读指令”字节（例如 `0x03`）。
        3. 发送目标地址。
        4. MCU开始时钟传输，闪存通过MISO线将数据逐位地输出给MCU。
        5. 取消选中芯片 (CS High)。
