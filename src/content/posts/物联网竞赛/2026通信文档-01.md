# 一、前端接收的数据

## 1. subData

**前端与硬件通信**

用于接收水循环系统实时运行数据。

字段说明：

-   `ID`：设备编号
-   `TIME`：数据采集时间
-   `T`：温度（Temperature），单位 ℃
-   `P`：压力（Pressure）
-   `F`：流量（Flow）
-   PumpStatus：水泵状态 1 运行 / 0 停止
-   HeatStatus：加热模块状态 1 加热 / 0 关闭

数据格式：

``` json
{
  "ID":"1",
  "TIME":"14:00:00",
  "Temp1":28,
  "Temp2":31,
  "Pressure":120,
  "Flow":35,
  "PumpStatus":1,
  "HeatStatus":1
}
```

------------------------------------------------------------------------

## 2. subTip

**前端、服务器与硬件通信**

用于接收系统异常报警信息。作用：水温超阈值、水压过高 / 过低、流量异常告警，APP 弹窗推送提醒

状态说明：

-   0 = 水温过高预警，1 = 管道压力异常，2 = 流量断流故障  3水温过低预警

数据格式：

``` json
{
  "ID":"1",
  "TIME":"14:16:55",
  "STATUS":1
}
```

------------------------------------------------------------------------

## 3.subControHistory

**前端与后端通信**

用于查询控制数据

Auto：自动控制，1为自动控制，0为手动控制

```
{
  "ID":"1",
  "TIME":"14:16:55",
  "PumpStatus": 0,
  "HeatStatus": 0,
  "Auto":1
}
```



## 4. subHistoryData

**前端与后端通信**

用于查询历史运行数据。

数据格式：

``` json
[
  {
     "ID":"1",
 	 "TIME":"14:00:00",
  	 "Temp1":28,
 	 "Temp2":31,
  	 "Pressure":120,
     "Flow":35,
  	 "PumpStatus":1,
     "HeatStatus":1
  },
  {
     "ID":"2",
 	 "TIME":"14:21:00",
  	 "Temp1":27,
 	 "Temp2":31,
  	 "Pressure":150,
     "Flow":31,
  	 "PumpStatus":0,
     "HeatStatus":1
  }
]

```

# 三、前端发送的信息

## 1. pubHistory

**前端与后端通信**

查询历史数据。

请求格式：

``` json
{
  "search":"1"
}
```

后端返回 `subHistoryData`。

------------------------------------------------------------------------

## 2.pubControlSearch

查询自动控制历史数据

请求格式：

``` json
{
  "search":"2"
}
```

后端返回 `subControHistory`。

## 2. pubControl

**前端与硬件和后端通信**

控制微型水泵。

字段说明：

-   PumpStatus：水泵状态 1 运行 / 0 停止
-   HeatStatus：加热模块状态 1 加热 / 0 关闭
-   Auto：自动控制，1为自动控制，0为手动控制
-   (由后端进行记录，通过subControHistory返回)

数据格式：

``` json
{
  "ID":"1",
  "PumpStatus":1,
  "HeatStatus":1,
  "TIME":"14:21:00",
  "Auto":1
}
```

------------------------------------------------------------------------



## 4.pubAlarmConfig

**前端与硬件通信**

设置报警阈值。

数据格式：

``` json
{
  "ID":"1",
  "TempTop":40,
  "TempMin":0,
  "PressureTop":150,
  "FlowMin":10
}

```

------------------------------------------------------------------------
