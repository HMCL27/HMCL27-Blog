# 2024前端数据的收发
## 1. 接收的数据
### 车辆信息
与硬件通信 (**实时信息**)
light1 为近光灯 light2 为远光灯 0为开1为关
V电压 T温度 C电量百分比
status 为车辆在线状态 0离线 1在线  PID车辆编号 PID电池识别号
```
{
"VID":"1234567890",
"PID":"12453142",
"status":0,
"V":220,
"T":26,
"C":60,
"light1":0,
"light2":0
}
```
主题：carInformation
### 异常信息
#### 1. 电池温度异常 前端和后端都要接收的数据 硬件发送

前端接收数据，弹框弹出异常。后端存储异常信息
```
{
"PID":"343513",
"T":68,
"time":"12:26:54"
}
```
主题：tempTip
#### 2. 电池剩余电量过低 前端和后端都要接收的数据 硬件发送

前端接收数据，弹框弹出异常。后端存储异常信息
```
{
"PID":"1354331",
"C":12,
"time":"22:35:42"
}
```

主题：electricityTip
#### 3. 电池电量无法到达最近换电站 前端和后端都要接收的数据 硬件发送
打开地图页面时，会向硬件发送最近换点站所需要的电量。
前端接收数据，弹框弹出异常。后端存储异常信息
```
{
"PID":"1234354",
"time":"22:35:42"
}
```
主题：subChargeTip
#### 3. 获取所有异常信息 前端与后端通信
**后端每次接收到异常信息后，更新数据库然后按照下列 json 数据格式向指定主题发送信息**。
status:
1 为温度异常，2 为电量过低，3 无法到达最近换电站

```
{
"PID":"1321543",
"status":1,
"time":"12:26:24"
},
{
"PID":"1325643",
"status":2,
"time":"22:26:24"
},
{
"PID":"1324543",
"status":3,
"time":"14:26:24"
}
```
主题：subAllTips
#### 4. 获取电池电量变化 前端与后端通信
后端收到前端发送的数据请求flag后 向该主题发送
```
{
"C":12,
"time":"08:25:33"
},
{
"C":54,
"time":"12:25:33"
},
{
"C":60,
"time":"14:25:33"
}
```
主题：CInfo
#### 5. 获取电池温度变化
后端收到前端发送的数据请求flag后 向该主题发送

```
{
"T":12,
"time":"08:25:33"
},
{
"T":54,
"time":"12:25:33"
},
{
"T":60,
"time":"14:25:33"
}
```

主题：TInfo
## 2. 发出的数据

#### 1. 灯光控制（近光灯）与硬件通信

```
{
"VID":"1234567890",
"lightHZ":1
}
```
主题：lightControl

1控制近光灯开2控制近光灯关
3控制远光灯开4控制远光灯关
#### 2. 喇叭控制 与硬件通信
```
{
"VID":"1234567890",
"speakerHZ":1
}
```
主题：speakerControl
#### 3. 电池电量不足30 与硬件通信
距离和坐标
```
{
"PID":"123453",
"x":20,
"y":10
}
```
主题：chargeTip
#### 4. 打开地图页面时 与硬件通信
通知硬件发送异常信息
```
{
"PID":"132453",
"path":45
}
```
主题：pubPath
