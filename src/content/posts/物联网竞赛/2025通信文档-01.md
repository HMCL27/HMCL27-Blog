# 智能灯杆系统通信文档
## 一、前端接收的数据

### 1. subData

**前端与硬件通信**

后端与硬件通信（当数据发生变化时，进行记录，当收到pubHistory发出的消息时，返回subHistoryData）

用于显示智能灯杆在线状态及实时运行数据。

字段说明：
  
-   `ID`：灯杆编号
-   `T`：温度（Temperature），单位 ℃
-   `H`：湿度（Humidity），单位 %
-   `L`：光照强度（Light）
-   `V`：电压（Voltage）
-   `I`：电流（Current）
-   `Status`：灯光状态（Status），1 开灯，0 关灯

数据格式：

``` json
{
  "ID":"1",
  "TIME":"14:00:00",
  "T":26,
  "H":60,
  "L":300,
  "V":220,
  "I":1.2,
  "Status":1
}
```

------------------------------------------------------------------------
### 2. subVideoData

**前端与服务器通信**

用于接收摄像头视频分析结果。

字段说明：

-   `ID`：灯杆编号
-   `TIME`：识别时间
-   `IMG`：识别后的图片(Base64)

数据格式：

``` json
{
  "ID":"01",
  "TIME":"14:08:55",
  "IMG":"base64xxxx"
}
```
------------------------------------------------------------------------
### 3. subTip
**前端、服务器与硬件通信**

用于接收异常报警信息。
状态说明：
-   当温度低于阈值发送1，温度高于阈值发送2，光照低于阈值发送3，光照高于阈值发送4

数据格式：

``` json
{
  "ID":"1",
  "TIME":"14:16:55",
  "STATUS":1
}
```

------------------------------------------------------------------------

## 4.subPicData

前端与后端通信

当后端收到pubPic消息后

后端需要将大模型返回的结果返回
processed_image为处理后的base64数据
inference_results为大模型返回的数据，为数组

```
{
  "processed_image": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD...",
  "inference_results": [
    {
      "class": 0,
      "confidence": 0.96,
      "label": "person"
    },
    {
      "class": 2,
      "confidence": 0.88,
      "label": "car"
    }
  ]
}
```

### 5. subHistoryData

**前端与后端通信**

用于查询灯杆历史运行数据。
数据格式：

# 二、前端发送的信息

## 1. pubTip

前端与后端通信
  
当前端判断出现异常状态后，将异常消息发出，后端进行储存，当后端收到pubSearchTip的消息时，将储存的异常信息从subTip返回
  
状态说明：

-   当温度低于阈值发送1，温度高于阈值发送2，光照低于阈值发送3，光照高于阈值发送4
``` json
{
  "ID":"1",
  "TIME":"14:16:55",
  "STATUS":1
}
```

------------------------------------------------------------------------
## 2. pubHistory

前端与后端通信
查询历史数据
后端返回subHistoryData
``` json
{
  "search":"1",
}
```

------------------------------------------------------------------------
## 3. pubLightControl

前端与硬件通信
控制 LED 灯。
字段说明：
-   `S=1` 开灯
-   `S=0` 关灯
``` json
{
  "ID":"1",
  "S":1
}
```
------------------------------------------------------------------------
## 4. pubAlarmConfig

前端与硬件通信

设置报警阈值。
``` json
{
  "ID":"1",
  "TempTop":40,
  "TempMin":0,
  "LightMin":50
}
```
------------------------------------------------------------------------
## 5. pubSearchTip

前端与后端通信
后端收到消息后，将储存异常消息从subTip里返回

``` json
{
  "search":"2",
}
```
## 6.pubPic
前端与后端通信
后端接收到消息后，调用YOLO大模型进行识别
前端传出的数据是image:Base64 编码的图片数据，以data:image/png;base64,开头。

# 三、后端处理的数据

### 智能识别接口案例
前端通过pubPic主题将base64数据传给后端，后端调用YOLO大模型处理图片

智能识别HTTP接口格式如下：

  接口地址：

  请求方式：POST

  请求体json:

  image:Base64 编码的图片数据，以data:image/png;base64,开头。

请求示例：

  {"image":"data:image/png;base64,iVBORwOKGgoAAAANSUhEUgAAAZ8AAAIICAY AAAAKW/UaAAAAAXNSR0IArs4c6QAAAARnQU1BAACxjwv8YQUAAAAJcEhZcwAADs MAAA7DAcdvqGQAAP+lSURBVHhe7P1rsyXJdSWILfeIOOc+81FZLwD1AEiABNDkkCOy Nd3WJEBaz8hkJpNspjWSjY3GZPoX+jRSzcj0c8ZkJpOZJFNP9......"}

  返回数据json:

  inference_results:数组，包含对图片的推理结果，每个元素是一个对象，包含class(类别编号)、confidence(置信度，0-1)、label(类别名称，其中person 代表识别到的行人)
  processed_image:经过处理后的图片数据，Base64编码
## 摄像头识别

系统接入摄像头设备后，由后端完成摄像头链路对接并输出对应视频流资源地址；

后端需提供给前src地址

前端页面可通过`<image>`组件，将组件`src`属性配置为该视频流地址，即可实现摄像头实时画面渲染展示
