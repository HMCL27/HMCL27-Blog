# 一.前端接收的数据
## 1.subCarData

前端与硬件通信

显示车辆的在线情况。当车辆在线时，能够显示当前联网的车辆信息，每一辆车可展示车辆编号 VID、电池识别号 PID、电池电压 V、电池温度 T、电池剩余电量百分比 C、灯光开关状态,管理系统能够显示车辆的在线情况
①.灯光开关状态  **light1近光灯，light2远光灯  1 开灯 ||0关灯**
②.管理系统能够显示车辆的在线情况  **connect :** **0 掉线 ||1 上线**
```
{
 "VID":"xxx",
 "connect":1,
 "PID":"xxx",
 "V":22,
 "T":60,
 "C":20,
 "light1":0,
 "light2":0
}
```

主题：subCarXY

```
{
 "VID":"xxx"
 "X":39,
 "Y":39
}
```
## 2.subTip

前端，服务器与硬件通信

**1 电池温度过高或者过低时，蜂鸣器报警并将“电池温度异常”信息传至管理系统**
**2 电池剩余电量过低时，蜂鸣器报警并将“电池电量过低”信息传至管理系统**
**3 电池剩余电量不足以到达最近的换电站，蜂鸣器报警并将“不能到达最近换电站”信息传至管理系统**  
**status :1 电池温度异常|| 2电池电量过低 ||3 不能到达最近换电站**
```
{
 "PID":"xxxx",
 "time":"09:54:55",
 "status":1
}
```
## 3.subHistoryTip

前端与服务器通信

**电池温度异常**
**电池电量过低**
**不能到达最近换电站**
管理系统前端上能正确展示来自车辆系统上传的所有异常信息
```
[{
 "PID":"xxxx",
 "time":"09:54:55",
 "status":"电池温度异常"
},{
 "PID":"xxxx",
 "time":"19:54:55",
 "status":"电池电量过低"
},{
 "PID":"xxxx",
 "time":"19:54:55",
 "status":"不能到达最近换电站"
}]
```
## 4.subAllMsg
前端与服务器通信

管理系统前端上能正确查看电池电量、电池温度的历史信息(绘制为图表)
```

[{
 "C":55,
 "T":60
},{
 "C":33,
 "T":55
}]
```
# 二、前端发送的信息
## 1.pubCarVID
前端与服务器通信

查询:发送电池PID,返回subAllMsg

```
{
 "PID":"xxxx",
}
```

## 2.pubTip

前端与服务器通信

查询:异常消息,返回subHistoryTip
```
{
 "search":1,
}
```

## 3.pubLightControl

前端与硬件通信

管理系统能发送控制信息控制车辆灯光，车辆系统收到信息后及时反应
1为近光灯开，2为近光灯关，3为远光灯开，4为远光灯关，0为自动控制
```
{
 "VID":"xxxx",
 "light":1,
}
```
## 4.pubSpeakerControl
前端与硬件通信

管理系统能发送控制信息控制车辆喇叭，车辆系统收到信息后及时反应
**speaker 1鸣笛**

```
{
 "VID":"xxxx",
 "speaker":1,
}
```
## 5.pubCharge

前端与硬件通信

车辆电量不足30%时，将最近充电站位置坐标向推车载系统上推送并进行显示

path:到达最近换电站的格子数

**如果电池当前电量无法到达充电站,向前端发布subHistoryTip主题,不能到达最近换电站。车辆需要救援前端地图已经会自动显示。**
```
{
 "VID":"xxxx",
 "PID":"xxxxxx",
 "x":26,
 "y":7,
 "path":25
}
```
