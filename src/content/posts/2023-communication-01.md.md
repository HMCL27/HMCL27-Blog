2023年物联网技能赛的通信文档
# 前端接收数据

#### **1.subHome**

与硬件通信：查询家居环境(温度、光照等)，具备一定的实时性

其中温度应以摄氏度(℃)为单位显示，光照条件应量化为数值(物理单位可使用 Lux，但本次竞赛中不做强制要求)；

```js
{
 "temp":36,
 "light":60,
 "time":"14:08:55"
}
```

#### **2.subTempTip**

前端与硬件通信：对特定的异常情况(如潜在火灾、照明控制等)进行**实时监控**，并向手机 APP 推送通知；

房屋高温预警

 "tip":0 为火灾警告

```js
{
 "time":"14:16:55",
 "tip":0
}
```

#### 3.subControlTip

后端，前端与硬件通信：照明自动控制：房间内设置一盏灯，灯可以手动控制，也可以自动控制，在一定规则下协同工作

1.白天时段：09：00-16：00

灯又处于开启状态时，系统将向手机APP 发送提醒，**在用户确认的前提下，自动关灯**:

前端会向**pubLighting主题中发送消息**

```js
{
 "time":"09:16:55",
 "light":0
}
```

2.夜晚时段：22：00-05：00

不展示信息，向**pubLighting主题中发送消息**

此时若灯仍处于开启状态，则系统自动关灯，并在APP 中留下记录，此场景不需要提醒用户，也不需要得到用户确认

#### 4.subHistoryTempTip

与服务器通信：查询火灾

```js
[{
 "time":"14:16:55",
 "tip":0
},{
 "time":"15:16:55",
 "tip":0
},{
 "time":"19:16:55",
 "tip":0
}]
```



#### 4.subHistoryControlTip

与服务器通信：查询照明控制

```js
[{
 "time":"9:16:55",
 "light":0
},{
 "time":"10:16:55",
 "light":0
},{
 "time":"14:16:55",
 "light":0
}]
```



# 前端发送的数据

#### 1.pubLighting

与硬件,服务器通信：手动控制灯的开关状态；

1 开灯||0 关灯

```js
{
 "light":1
 "time":"9:16:55"
}
```

#### 2.pubSpeaker

1 开||0 关

```js
{
 "speaker":1
}
```

#### 3.pubSys

与硬件通信：手机APP 上可手动设置系统时间、高温阈值、时长常量值(ST)

当温度传感器检测到室内温度异常升高，达到一定阈值(默认为70摄氏度，该阈值可以通过手机APP 在10摄氏度到100摄氏度范围内自由设置)

人员活动传感器长时间(常量值ST)未感应到人员活动，这里的时长ST 默认为600秒，该常量值可以通过手机APP在1秒到3600秒范围内自由设置

```js
{
 "tempTop":70,
 "ST":600
}
```

#### 4.pubTime

与硬件通信：发送系统时间

```js
{
 "time":"19:28:55"
}
```

#### 5.pubHistory

与服务器通信：发送查询

0 查询火灾||1 查询照明控制情况

```js
{
  "search": 0
}
```
